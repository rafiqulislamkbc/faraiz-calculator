# Hanafi Mirath & Faraiz Calculator - Flutter Mobile App

একটি পূর্ণাঙ্গ ও স্বয়ংসম্পূর্ণ হানাফি মিরাছ ও ইসলামিক ফারায়েজ ক্যালকুলেটর মোবাইল অ্যাপ্লিকেশন (Flutter 3+ Supported).

## 🌟 হালনাগাদকৃত বৈশিষ্ঠ্যসমূহ (Updated Features):
1. **জবিউল ফুরুজের ৩১টি সুনির্দিষ্ট বিধান (31 Zawil Furud Rules)** সম্পূর্ণ অ্যালগরিদমে যুক্ত।
2. **আসাবার ৪টি সুনির্দিষ্ট শ্রেণী (4 Asabah Classes)** এবং তাদের অগ্রাধিকার ক্রম (`শ্রেণী ১ > শ্রেণী ২ > শ্রেণী ৩ > শ্রেণী ৪`)।
3. **৪-ধাপের সম্পত্তি বণ্টন প্রক্রিয়া**:
   - ধাপ ১: জবিউল ফুরুজ বণ্টন
   - ধাপ ২: আউল (العول - ঘাটতি সমন্বয়)
   - ধাপ ৩: রদ্দ (الرد - উদ্বৃত্ত রক্তীয় অংশীদারদের ফেরত)
   - ধাপ ৪: আসাবা বণ্টন
4. **স্বয়ংক্রিয় হজব ফিল্টার (Auto Hajb Filter)**: পুত্র, পিতা বা নিকটবর্তী আসাবা থাকলে বঞ্চিত আত্মীয়দের অপশন স্বয়ংক্রিয়ভাবে আড়াল ও মান ০ করা।

## 🚀 কীভাবে রান করবেন (How to Run):

1. আপনার কম্পিউটারে Flutter SDK ইনস্টল করা থাকতে হবে।
2. প্রজেক্ট ফোল্ডারে টার্মিনাল ওপেন করুন:
```bash
flutter create .
flutter pub get
flutter run
```

3. রিলিজ APK বিল্ড করতে:
```bash
flutter build apk --release
```
